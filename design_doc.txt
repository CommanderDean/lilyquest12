Web App: Lily's 12th Birthday Quest
Built from Lincoln's 9th Birthday Quest app (itself originally built from Lily's 11th
Birthday Quest in 2025). Full circle!
==========================================

1. PROJECT OVERVIEW
The game is a single-page web application (index.html) with a wizard/magic theme.
Lily interacts with a crystal ball that plays audio clues guiding her to find physical
4-digit codes hidden around the house. Each code unlocks a puzzle by matching symbols
to the correct sequence. There are 10 puzzles in total. The game ends with a multi-phase
ending sequence that reveals the location of Lily's birthday present.

2. TARGET USER
Primary User: Lily (Dean's daughter, turning 12)
Considerations: She loves music, craft/art and books/stories — a few small nods to
these are woven into the note text and the finale sparkle effect, but the core wizard
theme, doors and puzzle mechanic are unchanged from Lincoln's version.

3. CORE GAMEPLAY LOOP
(A) Password screen: password is "twelvetoday2026" (placeholder — change if you like,
    search index.html for "const correct")
(B) Birthday modal dismisses, then crystal ball auto-plays intro.mp3
(C) For each of the 10 puzzles:
    - Crystal ball plays a location clue (audio)
    - Lily finds the hidden 4-digit code in the house
    - On the puzzle screen, Lily drags (or taps) symbols into 4 slots matching the code
    - Correct code: door unlocks with animation + sound, next clue plays automatically
    - Wrong code: shake animation + random nope sound
(D) After all 10 doors: ending sequence plays (are-you-sure1.mp3, are-you-sure2.mp3,
    location.mp3) revealing the gift location, with a gold sparkle flourish
(E) Lily can tap the crystal ball any time to replay the current clue

6. VISUAL DESIGN
    Theme: Wizard / Magic (dark blues, purples, gold accents) — kept as-is
    Fonts: MedievalSharp (headings), IM Fell English SC (body)
    Crystal ball: images/orb.png, orb2.png, orb3.png
    Orb glow pulses in sync with audio volume via Web Audio API
    Symbols: 16 SVG shapes, 8 per puzzle (deterministic based on puzzle seed —
    symbols.html and codes_in_symbols.html are still accurate, just cosmetically
    retitled for Lily)
    Doors: SVG shapes injected inline, unique per puzzle
    NEW: finale sparkle effect — small gold star/music-note/pencil flourishes burst
    around the orb when the gift location is revealed (search "spawnFinaleSparkles"
    in index.html). A light personal touch for her music/craft/story interests without
    a full reskin.

    Then enable GitHub Pages (Settings → Pages → Deploy from branch → main → /root).
